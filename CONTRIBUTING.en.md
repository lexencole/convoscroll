# Contributing

[简体中文](CONTRIBUTING.md) · [Development guide](docs/DEVELOPMENT.md)

Report bugs in an issue with reproduction steps and synthetic or redacted content. To contribute code, fork the repository, branch from the latest `main`, and open a PR. Discuss larger features first.

See the [development guide](docs/DEVELOPMENT.md) for setup and checks. Describe the change and validation in the PR, with images for UI or output changes.

Use Conventional Commits. Do not commit secrets, private content, or temporary output.
