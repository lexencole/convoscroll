# 话卷使用指南

[打开话卷](https://convoscroll.lexencole.com) · [返回首页](../README.zh-CN.md) · [English](USAGE.en.md)

## 编辑对话

点击左上角“话卷”打开文档菜单，可以新建对话、载入示例、导入文件或调整设置。

- 点击正文、标题或表格直接编辑。点击消息头像，修改名字、模型和其他身份信息。
- 点击“用户消息”或“AI 回复”添加消息；消息与内容旁的“…”提供复制、移动和删除操作。
- 在空白段落输入 `/` 添加代码、公式、表格、图片或文件。正文支持 Markdown 快捷写法。
- 使用工具栏撤销或重做。思考过程和工具记录可以折叠，并在导出设置中控制显示方式。

在“文档 → 语言”中切换界面语言；成图中的角色、状态等标签语言，在“标题和说明 → 成图语言”中设置。

## 导入内容

已有 Markdown 或话卷项目，在“文档 → 导入项目或 Markdown”中打开。

## 导出与备份

点击“预览”查看成图，再点“导出 PNG”。“文档 → 导出设置”可以调整画布宽度、清晰度、折叠内容和分段方式。长对话可导出为多张 PNG，打包下载。

通过“文档 → 导出项目”保存 `.convcanvas`，将可编辑的对话与附件一起备份，之后导入即可继续修改。

## 使用 Agent Skill

将 [convoscroll Skill](../skills/convoscroll/) 的完整目录添加到支持 Agent Skills 的客户端。提供聊天内容或截图，说明想保留哪些内容，以及是否需要摘要、翻译或脱敏，Agent 会整理并导出图片。

请使用支持浏览器操作和文件处理的 Agent，具体要求见 [Skill 说明](../skills/convoscroll/SKILL.md)。

## 保存与隐私

话卷在浏览器中处理对话和附件，不会上传到话卷服务器。使用 Agent 时，内容由你选择的 AI 服务处理。

当前项目会自动保存在浏览器中。清除网站数据会删除草稿；备份或换设备时，请先导出 `.convcanvas`。

项目文件包含附件原文件，分享前请确认其中的内容适合公开。
